OPTION 2: LOCAL DEVELOPMENT (RECOMMENDED FOR DEVELOPERS)
─────────────────────────────────────────────────────────

Step 1: Clone and setup
$ git clone <repo-url>
$ cd customer_support_agent
$ python -m venv venv
$ source venv/bin/activate  # Windows: venv\Scripts\activate
$ pip install -r requirements.txt

Step 2: Configure
$ cp .env.example .env
$ # Edit .env and add your GROQ_API_KEY

Step 3: Create directories
$ mkdir -p data/chroma_rag data/chroma_mem0 knowledge_base

Step 4: Open the notebook
$ jupyter notebook AI_Customer_Support_Agent_Complete.ipynb

Step 5: Run all cells from Phase 1 to Phase 9

Time needed: 10-15 minutes
Cost: FREE
Setup: Python 3.9+, pip

❓ TROUBLESHOOTING
═════════════════════════════════════════════════════════════════════════

Problem: GROQ_API_KEY not found
Solution: Make sure to add it in Colab Secrets (🔑 icon) or .env file

Problem: ChromaDB errors
Solution: Check data/ directory permissions: chmod -R 755 data/

Problem: LLM is too slow
Solution: Use 8B model (faster): llama-3.1-8b-instant

Problem: Token limits exceeded
Solution: Reduce llm_max_tokens in .env

See DEPLOYMENT.md for complete troubleshooting guide!
