🎯 QUICK START
═════════════════════════════════════════════════════════════════════════════

GOOGLE COLAB (RECOMMENDED):
1. Open: https://colab.research.google.com/
2. Upload: AI_Customer_Support_Agent_Complete.ipynb
3. Click 🔑 Secrets → Add GROQ_API_KEY from https://console.groq.com
4. Run all cells Phase 1-9
5. Done! Test with Phase 9 example

LOCAL DEVELOPMENT:
1. git clone <repo>
2. python -m venv venv && source venv/bin/activate
3. pip install -r requirements.txt
4. cp .env.example .env (add GROQ_API_KEY)
5. mkdir -p data/chroma_rag data/chroma_mem0 knowledge_base
6. python -m uvicorn customer_support_agent.main:app --reload
7. Visit http://localhost:8000/api/v1/docs

DOCKER:
1. docker-compose up -d
2. Visit http://localhost:8000/api/v1/docs
3. All services (API + ChromaDB) run automatically

   - Customer-level memories (individual interactions)
   - Company-level memories (organization patterns)
   - Automatic scope normalization

   - 4 customer support tools included
