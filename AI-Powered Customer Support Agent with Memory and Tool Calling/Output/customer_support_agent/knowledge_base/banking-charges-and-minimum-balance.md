# Banking Charges and Minimum Balance

## Minimum Balance
- Urban branch: INR 10,000 monthly average.
- Semi-urban: INR 5,000. Rural: INR 2,500.

## Non-Maintenance Fee
- INR 350 + taxes if balance falls below threshold (posted month-end).

## Other Charges
- SMS alert: INR 150/year. Debit card: INR 250/year.
- Closure within 14 days: INR 200 charge.
