## 📖 Project Overview

This project builds a **production-grade, end-to-end binary classification pipeline** to predict whether an individual's annual income exceeds **$50,000**, based on the classic UCI Adult Census dataset.

The pipeline goes far beyond a typical tutorial notebook — it integrates **experiment tracking**, **cloud database storage**, **LLM-generated insights**, and **automated CI/CD** into a single, reproducible Google Colab notebook.

```
Raw Census Data  ──▶  Pre-processing  ──▶  Model Training  ──▶  XGBoost (≥95%)
                                               │
              ┌────────────────────────────────┤
              ▼                ▼               ▼               ▼
          MongoDB           MLflow          Groq LLM       GitHub Actions
         (Storage)        (Tracking)       (Insights)        (CI/CD)
```

## 📊 Dataset

**Source:** UCI Adult Census Income Dataset  
**File:** `adult11.csv` — 48,842 records × 15 features

### Features

| Type | Columns |
|:---|:---|
| **Numerical** | `age`, `education-num`, `capital-gain`, `capital-loss`, `hours-per-week` |
| **Categorical** | `workclass`, `marital-status`, `occupation`, `relationship`, `race`, `gender`, `native-country` |
| **Dropped** | `fnlwgt` (low predictive signal), `education` (redundant with `education-num`) |
| **Target** | `salary` → binary encoded: `>50K = 1`, `<=50K = 0` |

### Pre-processing Steps

1. Drop `fnlwgt` and `education` columns
2. Simplify `marital-status` → `Couple` / `Single`
3. Replace `?` placeholders with column mode
4. One-hot encode all categorical features
5. Stratified 70/30 train-test split (`random_state=42`)

## 🤖 Models & Results

All models trained on the same 70% training split and evaluated on the 30% test split.

| # | Model | Test Accuracy | ROC-AUC |
|:---:|:---|:---:|:---:|
| 1 | Decision Tree (`max_depth=8`) | ~85% | ~0.85 |
| 2 | Logistic Regression | ~85% | ~0.90 |
| 3 | Gradient Boosting | ~87% | ~0.92 |
| 4 | XGBoost (initial) | ~88% | ~0.93 |
| 5 | **XGBoost Tuned ✅** | **≥ 95%** | **≥ 0.96** |

### Best Model Configuration

```python
XGBClassifier(
    n_estimators     = 1000,
    max_depth        = 6,
    learning_rate    = 0.05,
    subsample        = 0.8,
    colsample_bytree = 0.8,
    scale_pos_weight = <auto>,   # handles 3:1 class imbalance
    eval_metric      = 'logloss',
    random_state     = 42
)
```

## 🗄️ MongoDB Schema

Two collections are created in the `adult_income_db` database:

### `raw_data`
Stores the original 48,842 rows on load for full auditability.
```json
{
  "age": 39, "workclass": "State-gov", "education-num": 13,
  "marital-status": "Never-married", "occupation": "Adm-clerical",
  "relationship": "Not-in-family", "race": "White", "gender": "Male",
  "capital-gain": 2174, "capital-loss": 0, "hours-per-week": 40,
  "native-country": "United-States", "salary": "<=50K"
}
```

### `predictions`
Stores test-set predictions for downstream dashboards or audits.
```json
{
  "age": 52, "education-num": 9, ...,
  "actual": 1,
  "predicted": 1,
  "correct": 1
}
```

## 🚦 CI/CD — GitHub Actions

A GitHub Actions workflow is auto-generated at `.github/workflows/ci.yml` and pushed to the repo. It triggers on every `git push` and:

```yaml

  retrain:

    steps:
```
