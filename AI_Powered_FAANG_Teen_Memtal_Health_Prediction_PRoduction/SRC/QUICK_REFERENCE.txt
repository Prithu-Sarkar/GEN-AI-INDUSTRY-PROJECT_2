CLASS IMBALANCE HANDLING
========================
Problem: 38:1 imbalance ratio (only 31 depression cases out of 1200)
Solution: SMOTETomek (combines SMOTE oversampling with Tomek link removal)
Critical: Applied ONLY to training data - test set remains untouched
Result: Balanced training data for fair model learning

EVALUATION METRICS
==================
- Accuracy: Overall correctness (misleading for imbalanced data)
- Precision: True Positives / (True Positives + False Positives)
- Recall: True Positives / (True Positives + False Negatives) ← IMPORTANT
- F1-Score: Harmonic mean of Precision and Recall ← IMPORTANT
- Confusion Matrix: Breakdown of TP, TN, FP, FN
- Feature Importance: Which features drive predictions
